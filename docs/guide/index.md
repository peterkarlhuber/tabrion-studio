# User guide

This guide is for people who use Tabrion Studio. It describes what the current development version does.

!!! warning "Development version"
    The explorer, the data viewer and the diagnostics view come with the next work packages. What already works:
    starting and signing in, the connection profiles and the project's trust dialog, saved passwords, the settings,
    the keyboard and the command palette, the migration status and the SQL editor (reading statements only).
    Nothing is released; you install Studio from a commit of the repository.

- [Installation](installation.md): from a Git commit, with Python 3.11 or later.
- [Starting and stopping](starting.md): the `tabrion-studio` command, the sign-in link, one Studio per project
  folder, the logs.
- [Connections](connections.md): your profiles, the project's profiles and the trust dialog, passwords.
- [SQL editor](sql-editor.md): running reading statements, parameters, results, cancel, tabs and drafts.
- [Settings and keyboard](settings.md): language, theme, density, query limits, the command palette and the
  shortcuts.
- [How Studio protects your data](security.md): what Studio does and does not do, in short.
- [Troubleshooting](troubleshooting.md): the messages you may see, and what to do.

The architecture pages in this site explain how each part works and how it is tested.
