# Support

Tabrion Studio is an open-source project maintained in spare time. There is no commercial support and no guaranteed
response time.

* **Questions and problems:** first check the [documentation](docs/index.md). If that does not help, open an issue
  with the "Bug report" or "Feature request" template.
* **Security issues:** never in public issues; see [SECURITY.md](SECURITY.md).
* **Problems in the Tabrion library:** report them in the [tabrion](https://github.com/peterkarlhuber/tabrion)
  repository; problems in SQLite, PostgreSQL or the browser to those projects.

When you report a problem, include the Tabrion Studio version or commit, the Python version, the operating system
and browser, the database and its version, and the steps to reproduce. Remove passwords, connection strings and data
values first.
